# موقع مكتبة الشام

واجهة متجر عربية متجاوبة (RTL) لمكتبة دراسية، مبنية بـ HTML وCSS وJavaScript دون أطر عمل أو خدمات مدفوعة.

## تشغيل الموقع

1. فكّ ضغط المجلد أو افتح `index.html` في المتصفح.
2. لتجربة أدق، ارفع المجلد كما هو إلى استضافة صفحات ثابتة مثل GitHub Pages أو Netlify.
3. لا تغيّر أسماء مجلدات `css` و`js` و`assets` ما دامت الروابط الحالية مستخدمة.

## قبل النشر الفعلي

**المنتجات والأسعار الحالية بيانات تجريبية وليست إثباتاً لمخزون المكتبة أو أسعارها.** حدّث البيانات أولاً.

### تعديل المنتجات والأسعار

افتح `js/products.js`. كل منتج يحتوي على:

- `id`: معرّف فريد باللغة الإنجليزية، لا تكرره.
- `title`: اسم الملزمة الظاهر للزبون.
- `subject`: المادة.
- `grade` و`gradeLabel`: رمز المرحلة واسمها الظاهر.
- `kind`: القيمة `original` للأصلي أو `copy` للمستنسخ.
- `price`: السعر بالدينار العراقي، كرقم من دون فواصل.
- `summary`: وصف مختصر.
- `cover`: أحد الأنماط `chemistry`, `physics`, `biology`, `math`, `arabic`, `english`، ويمكن إضافة أنماط CSS جديدة.
- `symbol`: الرمز المرسوم على غلاف المنتج.
- `featured`: ترتيب المنتج الافتراضي.

احذف المنتجات التجريبية أو استبدلها ببياناتك الفعلية. إذا أضفت مرحلة جديدة، أضف لها زر فلتر في `index.html` ورمزها إلى `VALID_GRADES` في `js/app.js`.

### تفعيل الطلب عبر واتساب

افتح `js/config.js` وأدخل رقم واتساب المكتبة في `whatsappNumber` بصيغة دولية تشمل رمز الدولة، **أرقام فقط** ومن دون `+` أو مسافات. مثال شكلي غير حقيقي: `9647XXXXXXXXX` — استبدل X برقمك الفعلي. عند تركه فارغاً، لا يُرسل الموقع أي شيء تلقائياً، لكنه يسمح بنسخ رسالة الطلب.

### ملاحظات مهمة

- سلة المشتريات والمفضلة محفوظتان داخل متصفح الزبون باستخدام `localStorage`.
- تأكيد الطلب يفتح رسالة واتساب جاهزة للمراجعة، ولا ينفذ دفعاً إلكترونياً.
- هذه نسخة واجهة أمامية ثابتة؛ لا تحتوي على لوحة تحكم أو قاعدة بيانات أو إدارة مخزون مشتركة بين الأجهزة. لتحديث الأسعار والمخزون من مكان مركزي تحتاج إلى ربطها بخادم وقاعدة بيانات.
- خطا IBM Plex Sans Arabic وManrope يُحمّلان من Google Fonts عند توفر اتصال بالإنترنت، مع خطوط احتياطية عند تعذر الاتصال.
